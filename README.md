# 📱 Smart Mobile Shop Website

A simple and clean **Mobile Shop webpage** designed using **HTML and CSS** with an attractive **Orange & Blue theme**.  
This project is beginner-friendly and suitable for **college mini projects** and **practice**.

---

## ✨ Features
- Orange & Blue modern color theme
- Mobile product cards layout
- Product images with proper alignment
- Price highlighting
- Buy Now button
- Responsive grid layout (basic)

---

## 🛠️ Technologies Used
- HTML5  
- CSS3
